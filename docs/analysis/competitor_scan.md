# Competitor scan

Checked: 2026-11-02. [competitors.csv](competitors.csv) records primary product pages and deliberately leaves price blank where no comparable self-serve price was verified. Prices are vendor list prices in USD, not EUR, and may change. Products differ in scope, so price is descriptive rather than a like-for-like comparison.

| Alternative | What the official source confirms | Implication to test |
|---|---|---|
| [GitBook](https://www.gitbook.com/pricing) | Documentation publishing and AI features, with a free tier and paid site/user plans | A project PDF/Typst artifact may serve a different job from a docs website |
| [Mintlify](https://www.mintlify.com/pricing) | Documentation platform with web editor, API playground, and AI on paid plans | Teams already have strong publishing options |
| [ReadMe](https://readme.com/pricing) | API documentation platform with interactive reference, AI tools, and PDF export listed | PDF export alone is not sufficient differentiation |
| General AI chat | User can paste selected code and request a report | Compare groundedness, correction effort, and repeatability, not only prose quality |
| Manual templates and writing | No vendor required; full user control | Establish whether the tool saves enough review time |

No public source above establishes how many users need repository-to-formal-document generation. That demand requires interviews and usage tests. The proposed product's differentiation is a hypothesis: versioned formal document profiles, code-linked claims, editable Typst, and compiled PDF in one workflow.

## Repeatable scan instructions

For every alternative, record the official URL, access date, target audience, accepted input, output format, editing path, source-grounding behavior, template or standards claim, privacy controls, and price with billing terms. Mark unknowns instead of guessing. Recheck prices and features before any market or financial calculation.
